# k8s-rbac-ai-auditor

Система интеллектуального аудита RBAC-конфигураций Kubernetes с использованием большой языковой модели для выявления избыточных прав доступа и формирования рекомендаций по принципу минимальных привилегий.

Проект разработан в рамках магистерской выпускной квалификационной работы:
**«Система искусственного интеллекта на основе большой языковой модели для аудита конфигураций управления доступом по ролям в Kubernetes и формирования рекомендаций по принципу минимальных привилегий»**.

---

## Описание проекта

Проект предназначен для анализа конфигураций RBAC Kubernetes и выявления потенциальных проблем безопасности, таких как:

* избыточные права доступа;
* использование wildcard-разрешений;
* назначение привилегированных ролей;
* доступ к чувствительным ресурсам (secrets);
* нарушения принципа минимальных привилегий.

Система выполняет анализ RBAC-конфигураций и формирует рекомендации по повышению уровня безопасности.

---

## Архитектура

Система включает следующие основные модули:

* Загрузка YAML-конфигураций Kubernetes
* Парсинг и анализ RBAC-объектов (Role, ClusterRole, RoleBinding, ClusterRoleBinding)
* Выявление потенциально небезопасных разрешений
* Анализ конфигурации с использованием LLM
* Генерация отчета с рекомендациями

Общий процесс работы системы:

```text
RBAC YAML → Parser → RBAC Analyzer → LLM → Security Report
```

---

## Пример выявляемых проблем

Пример небезопасной роли:

```yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: insecure-role
rules:
- apiGroups: ["*"]
  resources: ["*"]
  verbs: ["*"]
```

Такая конфигурация предоставляет полный доступ ко всем ресурсам кластера и нарушает принцип минимальных привилегий.

* в DevSecOps-пайплайнах;
* для анализа RBAC-конфигураций перед развертыванием;

---

## Научная новизна

В отличие от традиционных инструментов статического анализа, система использует большую языковую модель для анализа конфигураций и формирования рекомендаций, что позволяет учитывать контекст конфигурации и выявлять сложные зависимости между правами доступа.
